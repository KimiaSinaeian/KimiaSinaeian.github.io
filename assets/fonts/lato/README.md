# Lato webfonts

Lato by Łukasz Dziedzic, distributed under the SIL Open Font License 1.1.

Source: `@fontsource/lato` version 5.3.0 (https://fontsource.org/fonts/lato).

Bundled Latin WOFF2 faces: Light (300), Light Italic (300), and Bold (700).
The light faces are used for body copy and research-card titles; the bold face
supports emphasized words in body copy. Existing title and label font choices
are preserved.
